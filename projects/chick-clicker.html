Chick Clicker

v1.2.1

What is Chick Clicker?

It's a fun clicker game with hungry chickens where you collect rare foods!

This is my most recent project, I started working on Chick Clicker in 2025 and released it in 2026. As the solo developer of this game, I programmed the game in C# using Visual Studio Code, customized the chickens and trees in Blender, and designed the user interface using Aseprite all while juggling a full-time job.

The main goal of Chick Clicker is to hatch chickens, collect rare foods, and grow your farm. Level up your chickens, buy upgrades, and watch your flock thrive while you relax.

If you wish to support the development of Chick Clicker, please wishlist it on Steam.

Features

  • 100% Handwritten Code
  • 3D Modeling
  • UI Menus
  • Character Customization
  • Save and Load System
  • Achievements
  • Multiple Languages
  • Day and Night Cycle
  • RNG Luck System
  • Offline Progression
