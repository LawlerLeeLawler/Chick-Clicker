What is SDF Terrain Generator?

It's a tool for generating procedural terrain using Signed Distance Fields (SDFs).

Using the power of SDFs, you can create unique and varied landscapes which you can then destroy or build upon.

The left video shows a rotating 3D object being scanned and converted into the SDF grid in realtime. The right video shows the SDF grid being modified and new meshes being generated on the fly.

Features

  • Destructiable Terrain
  • Building
  • Algorithmically Generated Terrain
  • Cave Systems
  • Custom Terrain
  • Near realtime mesh generation
  • Chunk based rendering
